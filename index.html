☁️ 클라우드 동기화 (Supabase)

모든 기기에서 같은 데이터를 공유합니다.
Supabase 연결 정보는 서버 함수(functions/supabase.js)에 들어 있어 별도 입력이 불필요합니다.

✅ 선생님 기록은 입력 후 몇 초 안에 선생님별로 서버에 자동 저장됩니다.
💡 최초 설정 방법 (관리자 1회)
① supabase.com 무료 가입 후 프로젝트 생성
② Project Settings → API에서 Project URL과 publishable key 복사
③ 저장소의 functions/supabase.js 파일 맨 위 SUPABASE_URL, SUPABASE_KEY 값에 입력 → main 브랜치에 반영되면 Cloudflare Pages에 자동 배포
④ Supabase SQL Editor에서 아래 쿼리 실행:
CREATE TABLE checklist_data (
  id TEXT PRIMARY KEY,
  org_name TEXT,
  admin_pw TEXT,
  teachers JSONB,
  state JSONB,
  updated_at TIMESTAMPTZ DEFAULT now()
);
INSERT INTO checklist_data (id) VALUES ('junior_2027'), ('senior_2027')
-- 다음 회기부터는 명단 행이 자동으로 만들어집니다
ON CONFLICT DO NOTHING;
⑤ 페이지를 새로고침하면 자동으로 서버와 연결됩니다
마감된 달은 교사가 수정할 수 없습니다. 관리자는 언제든지 해제 가능합니다.
